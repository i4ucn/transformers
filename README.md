# 变形跑车

一个单页 three.js 三维演示：黄色方块跑车与机器人之间的完整变形动画，参照电影《变形金刚》大黄蜂的风格。整个场景只用代码生成的几何体和程序化材质搭建，不依赖任何外部模型文件。

## 功能

- **一键变形**：「变汽车人」/「变回汽车」播放完整的正向或反向变形
- **分步演示**：共 5 步：车门展开 → 车头折叠 → 双臂伸出 → 双腿展开 → 头部升起。右侧步骤栏可以直接跳到任意一步
- **分解查看**：把可动部件沿各自方向拆开，并标注部件名称
- **机器人姿势**：挥手、抬臂、战斗姿态。在汽车形态下点击，会先自动变形再摆姿势
- **其他**：自动跟随系统的深色/浅色模式；支持 `prefers-reduced-motion`；适配移动端

## 运行

不需要构建，也不需要安装依赖：

- 直接双击 `index.html` 用浏览器打开（支持 `file://`）
- 或者在项目目录起一个本地静态服务：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

three.js 已放在 `vendor/` 目录里，离线也能渲染；只有标题字体从 Google Fonts 加载，断网时会改用系统字体。

## 代码导览（`index.html`）

- `STEPS` / `BOUNDS`：变形时间轴。0 表示汽车，1 表示机器人，每一步占一段区间
- `part()` / `pivotPart()`：创建可动部件，并给每个部件配置关键帧
- `POSES`：叠加在机器人形态上的姿势，数值是各关节的角度增量
- `applyTimeline()` → `applyExplode()`：每一帧依次计算时间轴、叠加姿势、自动落地，最后加上分解偏移
- `loftBody()` / `chamferBox()` / `fenderGeo()` 等：车身、倒角和轮拱这类程序化几何
- `phy()` 和 `TEX`：基于物理的金属漆材质，以及程序化生成的噪声和法线贴图

## 截图验证

`handoff-assets/verify-features.cjs` 用 Playwright 渲染汽车、机器人和各个姿势的截图，同时检查变形往返之后几何是否完全还原。需要先安装 `playwright`，并用 `CHROME_EXECUTABLE` 指定本机 Chrome 的路径：

```bash
node handoff-assets/verify-features.cjs
```

截图会输出到 `/tmp/`。

## 质量标准

- **电影级金属质感**：车漆、金属和玻璃不能有塑料感
- **零件之间真实衔接**：变形全程不能出现悬空、穿模或像外挂上去的部件。改动之前先算好交界处的坐标
